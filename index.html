    Cómo se calcula

    Costo variable unitariocompra o confección + empaque + otros directos + (comisión % × precio)
    Margen de contribución unitarioMCu = precio − costo variable unitario
    Razón de margen de contribuciónMC% = MCu ÷ precio
    Costos y gastos fijosCF = costos indirectos + administración + ventas + financieros
    Punto de equilibrio en unidadesPEu = CF ÷ MCu promedio ponderado
    Punto de equilibrio en pesosPE$ = CF ÷ MC% ponderado
    Margen de seguridad(ventas − PE$) ÷ ventas
    Utilidad operacionalMC total − CF
    Margen de utilidadutilidad operacional ÷ ventas
    Costo total unitariocosto variable + CF ÷ unidades vendidas
    Precio sugerido(costo directo) ÷ (1 − MC% objetivo − comisión %)
    Unidades para meta(CF + utilidad deseada) ÷ MCu ponderado
    Costo de adquisición de clientaCAC = pauta ÷ clientas nuevas
    Retorno de la pautaROAS = ventas ÷ pauta

    Base teórica: modelo costo-volumen-utilidad (Horngren; INCP, 2018). El análisis multiproducto supone que la mezcla de ventas entre referencias y canales se mantiene.
